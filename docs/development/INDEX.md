# Development Documents

- `setup.md`: 開発環境セットアップとタスク一覧。
  - 読むとき: 環境構築するとき・タスクやツールを足すとき。
- `philosophy.md`: 開発判断の基本原則（DRY・YAGNI・モック方針・根本原因対処）。
  - 読むとき: 設計判断に迷ったとき。全課題の前提。
- `architecture.md`: 設計原則・hooks・データ形式・UI・未決事項の SSoT。
  - 読むとき: hook・状態記録・要約抽出・UI を実装または変更するとき。
- `roadmap.md`: 時系列の計画と完了項目の SSoT。
  - 読むとき: 次に何をやるか決めるとき・課題を起票または完了したとき。
